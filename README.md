# Ansible Helper Scripts

[![Pipelines](https://github.com/DenZen1988/ansible-helper-scripts/actions/workflows/ci.yml/badge.svg)](https://github.com/DenZen1988/ansible-helper-scripts/actions/workflows/ci.yml)

A collection of ansible helper scripts. Those are meant to be used for virtual environments, they will most likely not work when used
on a regular/local installation of ansible.

## Available Scripts

### run\.sh

A unified script to run your ansible binaries from a virtual environment.

* Check the specific [README](./run.sh/README.md) for the usage.

### setup\.sh

A unified script to manage your virtual environment for ansible.

* Check the specific [README](./setup.sh/README.md) for the usage.
